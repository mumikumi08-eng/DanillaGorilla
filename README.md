# Random Quote Generator

**Автор:** Данила Карпухин

## Описание
GUI-приложение для генерации случайных цитат с возможностью фильтрации по автору и теме, а также добавления собственных цитат. История генерации сохраняется в JSON-файле.

## Функциональность
- Выбор случайной цитаты из предопределенного списка
- Добавление новых цитат (с проверкой на пустые поля)
- Отображение истории сгенерированных цитат
- Фильтрация истории по автору и теме
- Сохранение истории в формате JSON
- Загрузка истории при запуске программы

## Требования
- Python 3.6+
- Tkinter (обычно встроен в Python)
- Библиотеки: random, json, os, datetime, tkinter
